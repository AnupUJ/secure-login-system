A simple and secure login system built using Python Flask, HTML, CSS, and SQLite.

---

## Features

- User Registration
- User Login
- Secure Password Hashing
- Session Management
- Logout System
- SQL Injection Protection
- Responsive UI

---

##  Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS

##  How To Run

### 1. Install Required Libraries

```bash
pip install flask werkzeug
```

---

### 2. Run Project

```bash
python app.py
```

---

### 3. Open Browser

```plaintext
http://127.0.0.1:5000
```
